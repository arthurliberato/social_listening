# social_listening
A social listening platform made up of synthetic autonomous agents users and mention's authors.

## Development
```
npm install
npm run dev            # http://localhost:3000
npm run typecheck && npm run lint && npm run test:contrast
npm run test:e2e       # set PW_CHROMIUM_PATH to use a pre-installed Chromium
docker compose up      # app + postgres + mailpit
```
See CLAUDE.md for the build brief and milestones.
